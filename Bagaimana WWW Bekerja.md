# Bagaimana WWW Bekerja

WWW Bekerja dimulai saat pengguna mengetik URL di browser, yang kemudian mengirimkan permintaan melalui HTTP ke server web tempat data disimpan

Server merespons dengan mengirimkan file halaman web (HTML, CSS, JavaScript)

Langkah-langkah Detail Kerja WWW:
1. Pengguna Meminta Halaman: Anda memasukkan alamat situs (URL) di browser (Chrome, Firefox) atau mengklik tautan.
2. Informasi di simpan di dalam dokumen yang sering kita sebut halaman web.
3. Penerjemahan DNS: Browser menerjemahkan nama domain menjadi alamat IP server menggunakan sistem {!nav}DNS (Domain Name System){/nav}.
4. Permintaan ke Server (HTTP Request): Browser mengirimkan permintaan HTTP ke server yang alamat IP-nya didapat dari DNS, meminta file halaman web.
5. Permintaan ke Server (HTTP Request): Browser mengirimkan permintaan HTTP ke server yang alamat IP-nya didapat dari DNS, meminta file halaman web.
6. Respons dari Server (HTTP Response): Server menemukan halaman yang diminta dan mengirimkan file-file penyusunnya (HTML, CSS, JavaScript, gambar) kembali ke browser.
7. Interaksi: Pengguna dapat berinteraksi dengan elemen JavaScript, yang bisa memicu permintaan tambahan ke server jika diperlukan (misalnya memuat lebih banyak konten). 
8. Halaman Web adalah file-file yang di simpan dalam komputer tersebut di kenal dengan nama istilah web server
