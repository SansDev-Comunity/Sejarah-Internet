# World Wide Web

World Wide Web (WWW) adalah salah satu program yang di temukan oleh Tim Bernes-Lee pada tahun 1991.
awalnya hanya ingin menemukan cara untuk menemukan arsip-arsip riset nya untuk itu.

peranti lunak yang diberi nama enquire Tim Bernes-Lee berhasil menciptakan jaringan
yang menautkan berbagai arsip.

pada tahun 1989 Bernes-Lee membuat pengajuan untuk proyek pembuatan hyperteks global, pada bulan Oktober 1990
"Waring Wera Wanua" sudah dapat di jalankan dengan lingkungan CERN
